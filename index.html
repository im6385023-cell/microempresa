📘 Guía: hacer las imágenes PERMANENTES para todos los visitantes
  1. Sin configurar nada (modo local): tus imágenes se guardan solo en ESTE navegador (útil para probar). Los demás visitantes no las verán.
  2. Para que TODO el mundo las vea (gratis): crea una cuenta en supabase.com → New project.
  3. En Supabase: Storage → Create bucket → nombre: catalogo → activa Public bucket.
  4. En SQL Editor, pega y ejecuta este SQL (tabla de configuración):
create table if not exists public.site_images (
  id int primary key,
  urls jsonb not null default '{}',
  updated_at timestamptz default now()
);
insert into public.site_images (id, urls) values (1, '{}')
  on conflict (id) do nothing;
alter table public.site_images enable row level security;
create policy "lectura_publica" on public.site_images
  for select using (true);
create policy "admin_insert" on public.site_images
  for insert to authenticated with check (true);
create policy "admin_update" on public.site_images
  for update to authenticated using (true) with check (true);
  1. En SQL Editor ejecuta este segundo SQL (permisos del bucket):
create policy "lectura_obj" on storage.objects
  for select using (bucket_id = 'catalogo');
create policy "admin_insert_obj" on storage.objects
  for insert to authenticated with check (bucket_id = 'catalogo');
create policy "admin_update_obj" on storage.objects
  for update to authenticated with check (bucket_id = 'catalogo')
  with check (bucket_id = 'catalogo');
create policy "admin_delete_obj" on storage.objects
  for delete to authenticated using (bucket_id = 'catalogo');
  1. Authentication → Users → Add user: crea tu correo y contraseña de admin (ej. admin@snacksfrost.com).
  2. Settings → API: copia Project URL y la clave anon public.
  3. Abre este archivo index.html con un editor de texto y al final, dentro de CONFIG, pega tu URL y tu clave entre las comillas.
  4. Vuelve a subir la carpeta a Netlify (app.netlify.com/drop). Listo: cada imagen quedará publicada para siempre y visible para todos. ☁️
